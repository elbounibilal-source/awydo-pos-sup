# Awydo — نقطة بيع الجملة ونصف الجملة (نسخة الويب للتجربة)

تطبيق نقطة بيع لتجار الجملة ونصف الجملة بالمغرب: يعمل **بدون إنترنت**، ويُثبَّت على الهاتف كتطبيق (PWA)، ويزامن البيانات مع **Supabase** فور رجوع الاتصال.

> هذه نسخة التجربة لاعتماد تجربة الاستعمال. التطبيق النهائي هو تطبيق أندرويد أصلي (Kotlin)، ويُبنى بالسكيل `wholesale-pos-android`.

## محتوى المشروع

| الملف | الدور |
|---|---|
| `index.html` | التطبيق كاملاً في ملف واحد (العربية والفرنسية) |
| `sw.js` | يجعل التطبيق يفتح بدون إنترنت بعد أول زيارة |
| `manifest.webmanifest` + الأيقونات | التثبيت على الشاشة الرئيسية للهاتف |
| `config.js` | إعدادات Supabase الافتراضية (اختيارية) |
| `schema.sql` | قاعدة البيانات: جدولان ودالتان محميتان بكلمة سر المحل |
| `netlify.toml` | إعداد النشر على Netlify (بدون أي build) |

## 1) GitHub

1. افتح github.com ← **New repository** ← الاسم مثلاً `awydo` ← **Create repository**.
2. اضغط **uploading an existing file**، واسحب **كل محتوى** مجلد المشروع (وليس المجلد نفسه)، ثم **Commit changes**.

أو بالطرفية:

```bash
cd wholesale-pos-web
git init && git add . && git commit -m "Awydo — first version"
git branch -M main
git remote add origin https://github.com/<حسابك>/awydo.git
git push -u origin main
```

## 2) Supabase (المزامنة السحابية)

1. افتح supabase.com ← **New project** (اختر منطقة قريبة، مثلاً Europe West).
2. **SQL Editor** ← **New query** ← الصق محتوى `schema.sql` ← **Run**.
3. **Project Settings ← API Keys**: انسخ **Project URL** والمفتاح العام (**anon** أو **publishable**).
   - لا تستعمل أبداً مفتاح `service_role` أو `secret` في التطبيق.
4. (اختياري) ضعهما في `config.js` حتى لا تكتبهما على كل هاتف.

**الحماية:** الجداول مقفلة. التطبيق لا يستطيع إلا استدعاء `pos_push` و`pos_pull`، وكل استدعاء يحتاج **رمز المحل + كلمة سر المحل** (تُخزَّن مشفّرة بـ bcrypt). المفتاح العام وحده لا يكفي لقراءة أي شيء.

## 3) Netlify (الرابط للهاتف)

1. افتح app.netlify.com ← **Add new site ← Import an existing project ← GitHub** ← اختر `awydo`.
2. اترك Build command فارغاً، وPublish directory = `.` ← **Deploy**.
3. ستحصل على رابط مثل `https://awydo.netlify.app`. كل `git push` يحدّث الموقع تلقائياً.

(بديل سريع بدون GitHub: app.netlify.com/drop واسحب المجلد.)

## 4) التجربة على الهاتف

1. افتح الرابط في **Chrome** على أندرويد ← القائمة ⋮ ← **إضافة إلى الشاشة الرئيسية / تثبيت التطبيق**.
2. ادخل بـ **أحمد (صاحب المحل) — الرمز 1234**، أو **يوسف (كاشير) — 0000**.
3. القائمة ☰ ← **الإدارة ← المزامنة السحابية**:
   - Supabase URL والمفتاح العام.
   - **رمز المحل** (مثلاً `baraka-casa`) و**كلمة سر المحل** (8 أحرف على الأقل).
   - **حفظ وتفعيل المزامنة**. أول جهاز ينشئ المحل في السحابة.
4. جرّب بدون إنترنت (وضع الطيران): بِع، سدّد دَيناً… العمليات تبقى «معلّقة». أرجع الإنترنت ← تُرسل تلقائياً (☁).
5. على هاتف ثانٍ: نفس الرمز وكلمة السر ← **استرجاع من السحابة**.
6. للتحقق في Supabase: **Table Editor** ← `pos_events` (كل عملية) و`pos_shops` (آخر نسخة كاملة).

**ملفات PDF والصور:** على الهاتف، زر PDF / صورة يفتح نافذة المشاركة مباشرة (واتساب…). على الحاسوب يُحمَّل الملف.

## حدود نسخة التجربة

- البيانات محفوظة في المتصفح (localStorage). مسح بيانات المتصفح يمسحها، إلا إذا كانت المزامنة مفعّلة.
- المزامنة هنا: سجل لكل العمليات + آخر نسخة كاملة، و«الاسترجاع» يستبدل بيانات الهاتف. الدمج الذكي بين عدة أجهزة تبيع في نفس الوقت يأتي في تطبيق Kotlin (Outbox + ترقيم برمز الجهاز VNT-2026-D01-000123).
- الطباعة الحرارية المباشرة (بلوتوث) في تطبيق Kotlin. هنا: PDF أو صورة 80مم.
